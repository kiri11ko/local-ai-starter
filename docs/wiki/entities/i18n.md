# i18n

Source: [`local_ai_starter.py`](../../../local_ai_starter.py)

## Purpose
Интерфейс мастера на английском или русском. В коде и ярлыках — только английский.

## Key API
- `STRINGS` — `local_ai_starter.py:163`: словари `en` и `ru` с одинаковыми ключами.
  Подписи моделей — ключи `model.<profile.base>`, движков — `engine.<engine>`.
- `detect_lang()` — `local_ai_starter.py:397`. Порядок: `LOCAL_AI_STARTER_LANG` →
  `LC_ALL`/`LC_MESSAGES`/`LANG` (кроме `C`/`POSIX`) → macOS `defaults read -g AppleLanguages` →
  Windows `GetUserDefaultUILanguage` (первичный язык 0x19). Иначе `en`.
- `t(key, **kwargs)` — `local_ai_starter.py:424`, с откатом на `en`, если ключа нет в `ru`.
- `size_text(gb)` — `local_ai_starter.py:429`: «4.7 ГБ» / «80 МБ» с единицами языка.
