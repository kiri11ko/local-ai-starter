Running artificial intelligence on your own computer used to be a hobby for people with expensive graphics
cards. That has changed. Modern laptops have fast memory shared between the processor and the graphics
chip, and new open models are small enough to fit into it. A model with a few billion parameters can now
answer questions, write code, draw pictures and read text aloud without sending a single byte to the cloud.

There are real advantages. Your documents never leave the machine, so private notes, contracts and source
code stay private. There are no monthly bills and no rate limits. The model works on a plane or in a
cabin without internet. And because everything is local, you can measure exactly how fast it is and how
much memory it takes, and compare one model with another on the same task.

There are also limits. Local models are smaller than the largest cloud systems, so they make more mistakes
on hard problems. Long documents need a lot of memory. Video generation is still slow and takes minutes
for a few seconds of footage. The best approach is practical: try several models on the tasks you care
about, write down the numbers, and keep the one that gives the best result in the time you can afford.
